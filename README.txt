NOTES
- Open the Group123_CampusCafe folder in Visual Studio Code or Visual Studio.
- Open index.html in a browser to start.
- All pages share css/style.css and have responsive phone/tablet/desktop layouts.
- Images and the sample audio player use online URLs, so an internet connection is needed to display/play them.
- The contact form uses native HTML form validation and submits the entered fields as a GET request to the current page. It is a front-end demonstration and does not deliver messages to an inbox. Connect a form service or server to receive real submissions.
- Menu prices and café contact details are sample project content and can be edited by the group.
- If your instructor requires local media files, add them under images/ or media/ and update the corresponding src paths.
